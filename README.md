<br/>

A full-stack agricultural advisory platform combining a fine-tuned computer vision model with a multilingual conversational assistant, built to resolve farmer queries and deliver timely crop advisory.

| Aspect | Detail |
|---|---|
| **Stack** | ReactJS, Tailwind CSS, Rasa, ViT (Vision Transformer), TFLite |
| **Scale** | Trained on 87,000+ crop image samples |
| **Performance** | 94%+ classification accuracy on disease detection |
| **Security** | Blockchain audit trail deployed on Polygon Amoy testnet |
| **Impact** | SIH 2025 Grand Finale Runner-Up (Government of India) |
| **Repository** | [github.com/yshubhaamm](https://github.com/yshubhaamm) |

It's paired with a multilingual RAG-based chatbot for real-time farmer query resolution, real-time weather/market data integrations, a Farmer Community Platform, and an on-chain audit trail for transparency. This has been a sustained multi-semester anchor project threading together the majority of my applied AI work.
